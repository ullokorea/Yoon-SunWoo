# OOO · 당신의 여행 플래너 (부산 여행 MVP 웹사이트)

- `index.html` : 완성본. `images/` 폴더와 함께 호스팅(GitHub Pages, Netlify 등)하면 됩니다.
- `images/` : 구별 추천 장소 사진 (위키미디어 공용, 사진마다 저작자·라이선스를 페이지에 표시)
- `src/photos.json` : 사진 목록 (어느 장소에 어떤 사진, 저작자, 라이선스)
- `src/page.html` : 수정용 원본 (화면, 문구, 4개 언어 번역, 장소 데이터)
- `src/busan.json` : 부산 16개 구·군 경계 (통계청 2013 행정경계, southkorea-maps 공개 자료를 단순화)
- `build.sh` : 원본을 수정한 뒤 실행하면 `index.html`을 다시 만듭니다.
- `manifest.json`, `icons/` : 휴대폰 홈 화면에 앱처럼 추가할 때 쓰는 이름·아이콘

미리보기: https://claude.ai/artifact/Nsi7rH7d3rc3z6oBHrWfU9

## 설정해야 할 것
- **기상청 날씨**: `src/page.html` 의 `const KMA_KEY = '';` 에 공공데이터포털 '기상청_단기예보 조회서비스' 일반 인증키(Decoding)를 넣고 `./build.sh` 실행. 비워 두면 Open-Meteo 날씨로 대신 보여줍니다. 키는 페이지 소스에 보이므로 정식 공개 때는 서버를 통해 호출하세요.
- **임시 위치**: 앱 전체 기준 지역은 부산진구(서면역)로 임시 설정되어 있습니다. 위치 기능은 `WX_ALLOW_GEO` 로 다시 켤 수 있습니다.

## 앱 주요 기능 (2026-11-15 기준)
- 지금: 언어 선택, 현재 날씨 + 16개 구·군, '나만의 특별한 여행 코스 만들기'(지역·날짜·시간·날씨·예산·관심 → '여행 코스 만들기'), 조건 없을 때 '오늘의 추천 코스'
- 둘러보기: 서면 약도, 내 위치, 추천 코스 핀 번호와 목록 번호
- 교통: 목적지 검색, 서면역에서 가는 법, 노선·요금·교통카드·팁, 교통 한국어
- 도움: 질문하기(Claude 맞춤 코스), 번역(입력·음성), 한국어 문장 카드, 주변 필수 정보
- 웹페이지 왼쪽 (2026-11-16 갱신): 소개 문구, '앱 화면 구성'(탭별 기능 카드, 누르면 앱이 그 탭으로 이동), '직접 눌러보기' 7가지, 해결하려는 문제·MVP 범위·수익화·검증 계획
- 미리보기(claude.ai)에서만 되는 기능: Claude 질문·번역·교통 안내, 음성 입력. 다른 곳에 호스팅하면 규칙 기반 답변·구글 번역 새 창·지도 앱 링크로 대체됩니다.

## 리뷰 · 불편사항 신고
- 미리보기(claude.ai)에서는 리뷰가 모든 방문자에게 공유되고, 불편사항 신고는 소유자만 볼 수 있어요. Claude에게 "신고 내용 보여줘"라고 하면 읽어 드려요.
- 다른 곳에 호스팅하면 둘 다 그 기기(브라우저)에만 저장돼요. 정식 공개 전에는 서버(DB)가 필요해요.

## 공개 전 확인할 것
- 음식점 정보, 교통 요금(택시 기본요금 출처 엇갈림), 정거장 수·소요 시간은 웹 검색과 계산 기반이라 확인이 필요합니다.

## 휴대폰(갤럭시)에서 앱으로 쓰기
- 화면 폭이 600px 이하인 휴대폰에서는 앱 화면만 전체 화면으로 보입니다. 웹사이트 전체를 보려면 주소 끝에 `#site`, 컴퓨터에서 앱만 보려면 `#app`.
- 호스팅: 이 폴더 전체(index.html, images, icons, manifest.json)를 Netlify Drop(https://app.netlify.com/drop)에 끌어다 놓거나 GitHub Pages에 올리면 공개 주소가 생깁니다.
- 갤럭시에서 그 주소를 Chrome 또는 삼성 인터넷으로 열고 메뉴 → '홈 화면에 추가'(또는 '앱 설치')를 누르면 OOO 아이콘으로 실행됩니다.
