# 법률 검토 필요 항목 (한국 출시 전제)

> ⚠️ 이 문서는 **검토가 필요한 항목 목록**이다. 법률 자문을 받지 않았으며, 어떤 항목도 "준수 완료"로 판단하지 않았다.
> 앱·웹의 약관·동의 문구는 모두 **초안**으로 표시되어 있다.

## 1. 개인정보 보호법

| 항목 | 현재 구현 | 검토 필요 |
|---|---|---|
| 수집 항목·목적·보유기간 고지 및 동의 | 가입 시 필수(약관·개인정보)/선택(위치·마케팅) 분리 동의, 동의 시각 저장 | 고지 문구 확정, 필수/선택 구분 적정성, 만 14세 미만 가입 제한 여부 |
| 최소 수집 | 이메일·닉네임·(선택)휴대폰. 실명·생년월일 미수집. 위치 좌표는 서버에 저장하지 않음 | 노쇼 분쟁 대응에 연락처가 필요한지 |
| 제3자 제공 (소비자 → 점주) | 점주에게 닉네임·마스킹된 휴대폰·예약 내역만 | 점주 제공을 "제3자 제공"으로 볼지, 별도 동의 필요 여부 |
| 처리 위탁 | (운영 시) Supabase·Vercel·Expo 등 해외 클라우드 | 처리 위탁·국외 이전 고지 |
| 보유기간·파기 | 탈퇴 시 즉시 가명화(이메일·닉네임·전화·즐겨찾기·알림 삭제), 예약 기록은 식별정보 없이 보존 | 예약·거래 기록 보존 기간 근거(전자상거래법 등) 및 기간 경과 후 자동 파기 배치 (미구현) |
| 안전성 확보 조치 | 비밀번호 scrypt 해시, 세션 토큰 해시 저장, 역할 기반 접근, 관리자 화면 마스킹, 감사 로그 | 접속기록 보관 기간, 개인정보 처리방침 공개, 내부관리계획 |
| 이용자 권리 | 앱 내 탈퇴, 알림 수신 설정 | 열람·정정·처리정지 요청 창구 |

## 2. 위치정보의 보호 및 이용 등에 관한 법률

| 항목 | 현재 | 검토 필요 |
|---|---|---|
| 위치기반서비스사업 신고 | 미신고 | 개인위치정보를 이용한 서비스 제공 → **위치기반서비스사업 신고 대상 여부** 확인 (방송통신위원회) |
| 위치정보 이용 동의 | 가입 시 선택 동의 + OS 권한 요청, 거부 시 수동 지역 선택 | 위치기반서비스 이용약관 별도 동의 필요 여부 |
| 위치정보 이용·제공사실 확인자료 | 좌표를 서버에 저장하지 않음 (요청 시에만 사용) | 요청 로그(인프라 액세스 로그)에 좌표가 남는지 확인 — 현재 GET 쿼리스트링으로 전달됨 → POST 바디 전환 또는 로그 마스킹 검토 |

## 3. 전자상거래·표시광고

| 항목 | 검토 필요 |
|---|---|
| 할인 표시 | 정상가·할인가를 함께 표시하고 있음. 정상가가 실제 판매가인지 점주 확인 책임·약관 명시 |
| "최대 50%" 등 광고 문구 | 실제 참여 매장 최대치로만 표시 (계산값). 과장 광고 해당 여부 |
| 통신판매중개자 고지 | 현장 결제라도 중개 플랫폼으로서 고지 의무 해당 여부 |
| 노쇼 제재 | 현재 표시만 함. 이용 제한 정책을 도입하면 약관 근거 필요 |

## 4. 날씨·재난 관련

| 항목 | 검토 필요 |
|---|---|
| 기상청 데이터 이용 조건 | 공공데이터포털 이용허락 범위(출처 표시 등) |
| 태풍 프로모션 | 재난 상황 영업 유도 비판 가능성 → 위험 시 예약 자동 차단·안전 문구 구현됨. 지자체 재난안전 지침과 충돌 여부, 사고 시 책임 범위 약관 |
| "안전 확인" 운영자 판단 | 운영자 수동 전환의 판단 근거·책임 (감사 로그로 기록 중) |

## 5. 기타
- 사업자 진위 확인(국세청 API) 미연동 — 허위 매장 등록 리스크
- 앱 스토어 정책: 계정 삭제 기능(구현됨), 위치 권한 사용 목적 문구(반영됨)
- 점주 이용약관: 할인 이행 의무, 확정 예약 조건 보존 의무, 수수료(향후)
